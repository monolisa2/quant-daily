# 데일리 퀀트 브리핑 (quant-daily)

평일 아침, 코스피·코스닥 전종목을 13개 전략으로 훑어서 **단타 / 스윙 / 장투** 세 구간의 후보를 뽑아 웹사이트에 발행합니다.

**→ https://monolisa2.github.io/quant-daily/**

```
GitHub Actions (평일 KST 06:30)
  ├─ 네이버 금융 전종목 시세 수집 (약 2,600종목)
  ├─ 지표 시계열 계산 → 13개 전략 스크리닝
  ├─ 백테스트 결과와 대조 (월 1회 자동 재계산)
  ├─ signals/YYYYMMDD.json 커밋   ← 그날 픽 기록, 다음날 추적용
  └─ docs/ 정적 HTML → GitHub Pages 배포
```

API 키가 하나도 필요 없습니다. LLM도 안 씁니다. 전부 계산으로만 돌아갑니다.

## 무엇이 나오는가

### 1. 단타 / 스윙 / 장투 탭

| 구간 | 보유 기간 | 목표 | 배치 전략 |
|---|---|---|---|
| 단타 | 3거래일 | +3% | 거래량 폭증, 급등+종가강세, 상한가 근접, 과매도 반등 |
| 스윙 | 20거래일 | +8% | 52주 신고가, 골든크로스, 눌림목, 변동성 수축, 낙폭과대 |
| 장투 | 120거래일 | +20% | 12-1 모멘텀, 꾸준한 우상향, 저변동 우량, 외국인 지분율 |

### 2. 전략마다 실제 백테스트 성적

2022.05 ~ 2026.03, **823,394 종목-일**을 전수 검증했습니다.
모든 전략 × 모든 보유기간(3/20/120일) 조합을 계산해서 카드에 배지로 붙입니다.

**승률이 아니라 `시장대비(edge)` 를 봐야 합니다.** 검증 기간이 강세장이라
조건을 통과한 종목을 아무거나 사서 120일 들고만 있어도 평균 +9.28%였습니다.
벤치마크를 얼마나 이겼는지가 실력입니다.

| 전략 | 단타 3일 | 스윙 20일 | 장투 120일 |
|---|---:|---:|---:|
| 상한가 근접 | **+2.93%p** | **+3.21%p** | -5.94%p |
| 52주 신고가 돌파 | +0.49%p | **+2.24%p** | +2.88%p |
| 12-1 모멘텀 | +0.17%p | +1.35%p | **+5.53%p** |
| 상승추세 눌림목 | -0.03%p | +0.56%p | **+4.60%p** |
| 골든크로스 | -0.13%p | -0.31%p | -1.10%p |
| 낙폭과대 턴어라운드 | -0.74%p | -3.27%p | **-9.56%p** |

같은 신호도 **언제 파느냐로 결과가 뒤집힙니다.** 상한가 근접은 단타로는 최고, 장투로는 최악입니다.
엣지가 마이너스인 전략은 사이트에서 흐리게 표시되고 "과거엔 손해" 라벨이 붙습니다.

### 3. 종목별 과거 성적

같은 신호라도 종목마다 잘 듣는 게 있고 안 듣는 게 있습니다.
각 후보 옆에 "이 종목에서 이 신호 과거 N회 · 승률 X%"가 함께 나옵니다.
표본 3회 미만은 "표본부족"으로 표시합니다.

### 4. 손절 / 익절 참고선

각 전략 카드에 과거 이 신호 후의 **최대 상승폭(MFE) / 최대 하락폭(MAE) 중앙값**이 적혀 있습니다.
감이 아니라 통계로 손절선을 잡으라는 뜻입니다.

## 설치

### 1. 퍼블릭 저장소로 올리기

퍼블릭이어야 Actions와 Pages가 무료입니다.

### 2. Pages 켜기

**Settings → Pages → Source → Deploy from a branch → `main` / `docs`**

주소는 `https://<아이디>.github.io/quant-daily/` 가 됩니다.

### 3. 첫 실행

**Actions → Daily Quant Brief → Run workflow**. 1~2분 걸립니다.
`backtest.json` 이 이미 들어 있어서 첫 회부터 성적표가 나옵니다.

## 운영

### 관심종목 추가

`watchlist.json` 의 `codes` 에 종목코드(6자리)를 넣으면 리포트 최상단에
현재 상태 + 오늘 걸린 시그널 + 그 종목의 과거 시그널 성적표가 따로 나옵니다.

```json
{ "codes": ["000660", "005930"] }
```

### 전략 추가 / 수정

`core.js` 의 `STRATEGIES` 배열에 객체 하나 추가하면 끝입니다.

```js
{ id:'myidea', horizon:'swing', name:'내 아이디어',
  origin:'출처', why:'왜 쓰는지', caution:'주의점',
  pick: (r) => r.rsi14 < 40 && r.aboveMa120,   // boolean
  score: (r) => r.ret20 }                      // 정렬 기준
```

추가한 뒤에는 백테스트를 다시 돌려야 성적이 나옵니다.

```
node run.mjs --backtest
```

또는 `backtest.json` 을 지우면 다음 실행 때 자동으로 새로 계산합니다.

### 사용 가능한 지표 필드 (`r`)

```
close, ret1/2/3/5/10/20/60/120/240, mom12_1, ma5/20/60/120,
aboveMa20/60/120, goldenCross, deadCross, w52h, w52l, fromHigh, fromLow,
newHigh, nearHigh, newLow, rsi14, rsiPrev, volRatio, avgVal20, tradeVal,
vola20, volaSqueeze, closeStrength, frgnRatio, frgnChg5, frgnChg20, capEok
```

### 발송 시각

`.github/workflows/daily.yml` 의 `cron: '30 21 * * 0-4'` — UTC 기준이라 KST 06:30, 평일만입니다.
GitHub 크론은 부하에 따라 **5~20분 늦게 시작될 수 있습니다.**

### 60일간 커밋이 없으면 크론이 멈춥니다

GitHub 정책입니다. 이 워크플로는 매일 커밋을 만들어서 자동으로 유지됩니다.

### 로컬에서 돌려보기

```
node run.mjs
```

Node 20 이상이면 됩니다. 의존성 설치 필요 없습니다.

## 데이터와 한계

- 출처: 네이버 금융 공개 엔드포인트 (전종목 시세, 일봉, 지수, 환율, 종목 뉴스)
- 필터: 시가총액 1,000억원 이상, 20일 평균 거래대금 5억원 이상, 우선주·스팩·ETF/ETN 제외
- 백테스트에 **수수료·세금·슬리피지가 반영되지 않았습니다.** 단타 전략은 특히 실제 수익이 더 낮습니다.
- **생존편향**이 있습니다. 현재 상장된 종목만 대상이라 그동안 상장폐지된 종목이 빠져 있습니다.
- 장중에 돌리면 값이 실시간으로 흔들립니다. 장 마감(15:30 KST) 이후 기준이 정상입니다.
